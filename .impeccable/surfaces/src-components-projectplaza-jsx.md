# Project Plaza

- Scope: `/projects` public project center, including all-projects and competition scopes.
- Mode: Operate.
- Audience: hackathon participants, builders, organizers and public visitors comparing work.
- Job: choose a stable browsing scope, understand the current event, find projects, and take the correct submission or continuation action.
- Primary action: submit to the selected competition when available; otherwise browse and publish a long-term project.
- Proof/content: real public project cards, competition works, author, major, award/rank, GitHub and deployment evidence.
- Constraints: preserve the existing dark hackathon identity and global shell; the competition index never disappears; URL owns competition scope; no fabricated evidence or ownership; zh/en and 390px support.
- Direction: a persistent competition archive index above a stable project workspace. Event context is a subordinate program sheet, not a replacement page.
- Memorable moment: switching competitions changes the program sheet and work catalog while the archive index and controls remain visibly fixed.
- Unresolved decisions: none for this rebuild.
