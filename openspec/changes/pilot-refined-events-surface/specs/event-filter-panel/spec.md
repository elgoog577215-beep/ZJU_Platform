## ADDED Requirements

### Requirement: 活动筛选和视图切换具有可感知边界

活动页面 SHALL 让桌面筛选入口、组织筛选、结果统计和卡片/列表视图切换形成连续但不嵌套的精致工具层。所有可点击控件 MUST 通过边框、表面、文字或焦点态与背景区分；卡片/列表切换 MUST 由整组外边界提供操作区域识别，并通过蓝色底线、文字对比和语义状态共同表达当前项。

#### Scenario: 用户切换卡片与列表

- **WHEN** 桌面用户查看“卡片 / 列表”切换器
- **THEN** 切换器具有轻薄可见的整组外边界和两个可识别操作区域
- **AND** 当前视图保留蓝色底线、清晰文字对比和 `aria-pressed=true`，不使用厚重的实体分段填充
- **AND** 非当前项仍保持可读和可聚焦。

#### Scenario: 用户浏览筛选工具

- **WHEN** 桌面用户浏览分类、学院、排序和组织筛选
- **THEN** 控件按任务分组并保持稳定对齐
- **AND** 页面不得使用无边界文字按钮让控件与背景混在一起
- **AND** 工具层不得通过多层卡片嵌套制造层级。
