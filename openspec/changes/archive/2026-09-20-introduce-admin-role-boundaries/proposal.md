# Why

现有后台只有全量管理员。需要保留开发人员的完整治理能力，同时让普通管理员使用大部分日常运营功能，并隔离账号隐私、报名、凭据和系统配置。

# What Changes

- 两级管理员共用现有后台，新增按模块配置的八组权限，覆盖 13 个日常运营入口。
- 集中设置权限，服务端按当前数据库权限执行请求并审计授权变更。
- 保护隐私和系统接口，公开页面写入使用字段白名单，编辑已有内容保留发布主体。
- 完成身份显示、退出、越权深链、移动端菜单滚动和私有备份恢复。

# Capabilities

## New Capabilities

- `admin-access-controls`: 两级管理员、模块授权、撤销和敏感数据边界。

# Impact

涉及 users 附加字段、认证和授权中间件、业务控制器、后台路由、React 管理台、中英文文案及回归测试。普通管理员默认支持全站运营；账号、报名、采集凭据、模型、完整审计与系统配置保留为开发管理员专属。
