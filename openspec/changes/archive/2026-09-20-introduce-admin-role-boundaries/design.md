# 模型与取舍

保留账号主体、审核发布能力和后台权限三轴。开发管理员使用 admin/platform，普通管理员使用 operator/operations，防止触发历史 role=admin 绕过。两级共用现有后台；普通管理员在设置时默认勾选八组运营能力，由开发管理员按需删减。后台模块能力不能改变组织成员或账号身份。

# 业务边界

运营权限覆盖总览、活动、文章与媒体、AI 资料与社区、审核、项目治理、合作方、分类标签与公开页面。活动和内容模块包含审核、编辑和删除。审核队列按授权的资源类型过滤。账号、报名、采集凭据、模型、完整审计、文件与数据库管理继续仅限开发管理员；公开页面设置采用精确字段白名单。普通管理员的项目治理响应移除联系人信息与举报原文，总览移除系统和审计信息。发布主体选项只包含公开组织、自身主体与所编辑内容的现有主体，保留原归属。

# 认证与授权

每个请求查当前 users 行，失效会话返回 401，数据库故障返回 503，不回退 JWT 权限。auth_version 在强制下线和密码变更时递增。admin/access 更新在独立连接的 BEGIN IMMEDIATE 事务内重查操作者，校验乐观锁、自身操作与最后管理员，更新权限并写审计。旧资料接口禁止修改后台身份字段。未知能力和通配符不会授予普通管理员权限。

# 交互

保留六域导航，系统与审计增加“管理员与权限”。原账号页保留资料和密码重置，角色与权限集中在新入口。两级使用同一批原工作区组件；无权限深链不挂载模块。能力在聚焦及每 15 秒刷新，失败关闭后台内容并支持重试、退出。移动导航独立滚动，关闭后恢复页面滚动。敏感系统信息不以空白假数据展示给普通管理员。

# 迁移与恢复

首次对已有用户的文件数据库执行 VACUUM INTO，私有保存并检查完整性与账号数；失败阻止启动。新增字段与旧管理员规范化事务执行、可重复运行。恢复先停服务、保全当前数据及 WAL/SHM，在副本验证快照，再与匹配的发布版本一起切换；保全快照后业务变化，不得盲目覆盖或批量提升普通管理员。
