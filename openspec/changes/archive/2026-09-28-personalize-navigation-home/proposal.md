## Why

首页当前对所有账号展示同一网址目录，账号常用链接接口未接入现有界面。用户需要自己安排网址板块、跨设备保存，并将整理成果导出或分享供他人复用。

## What Changes

- 保留首页视觉与公开目录；登录后使用账号专属网址分组，支持板块及链接增删改、排序、恢复默认。
- 导出浏览器书签 HTML 与完整 JSON 配置；JSON 支持恢复，导入先进入草稿。
- 首页内提供开放广场：主动选择已保存板块生成公开副本，别人预览后追加到个人首页，不覆盖已有内容。
- 分享复用现有信任等级和审核权限。普通用户待审核；作者可以撤回，管理员可以审核、下架。
- 新增账号配置与分享快照表及接口；旧常用链接保留并在首次编辑时承接。

## Capabilities

### New Capabilities

- `navigation-home`: 账号网址工作区与可复用分享。

## Impact

React 首页、navigation API、SQLite 幂等迁移、现有权限工具。仅处理网址分组，不加入活动或文章组件。迁移只加表；回退代码时保留新表和旧接口，避免丢数据。部署前保留数据库备份。
