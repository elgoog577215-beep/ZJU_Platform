## Context

现有 HomeDirectory 直接展示 directory.js；user_navigation_shortcuts 已有账号隔离和版本控制。新增能力沿用首页布局、主题、身份与权限工具，不把网址集合当作项目广场项目。

## Decisions

1. 每账号保存一份有序分组快照（最多 40 组、总计 600 链接，每组 100 链接）；首次使用以公开目录和已有常用链接为起点。保存使用 version 原子条件更新，多设备冲突保留草稿并提示重新载入。
2. 编辑在首页内完成：左侧选择与调整板块，右侧编辑网址；增删与排序只作用于草稿，保存成功后用于日常首页。取消可回到已保存内容。
3. 导出 HTML 保留分组/链接顺序，文本及属性转义，仅接受 HTTP(S)。JSON 携带 schemaVersion，导入验证后进入草稿，不直接覆盖。
4. 分享从服务器已保存配置按板块 ID 提取，忽略客户端传来的他人账号或额外内容。公开数据只来自独立快照；私人后续编辑不自动公开。发布前显示所选全部链接。
5. 分享列表有公开、我的分享、审核范围；复用 canBypassReview 和 canReviewResource 权限。公开列表只返回 approved，普通用户可撤回自己的分享。读写禁止缓存，私有接口必须认证。
6. 广场采用首页内 URL view 状态，提供预览、追加和书签下载。追加生成新本地 ID，先成为草稿再保存；作者撤回不删除别人已保存的副本。
7. 键盘及手机可用上移/下移操作，不依赖拖动。支持中文、英文、明暗主题；账号切换卸载整个工作区，迟到响应不能串号。写请求不自动重试。

## Validation

临时 SQLite + 真实认证/HTTP 测试账号隔离、并发冲突、URL 校验、审核及撤回、分享快照边界、迁移重入；前端测试导出与导入；桌面/手机浏览器验证登录编辑保存刷新、分享与追加、失败恢复。构建与定向 ESLint。
