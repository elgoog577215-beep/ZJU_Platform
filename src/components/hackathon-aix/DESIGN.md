# AI+X 第二届赛事界面

本目录第二届视觉尚未获得验收。用户于 2026-09-29 要求转到全新项目、全新对话独立重做；本目录停止视觉迭代，以下为未获批准的中间实现记录，不作为新项目的设计依据。第一届页面保留。

## 视觉与阅读

固定深色背景，使用真实创作现场摄影建立赛事氛围。首屏左侧完整呈现赛事名、介绍、参赛对象和时间地点，右侧为摄影作品及明确的首届来源说明。摄影不冒充本届活动。删除装饰性栏目编号、巨幅抽象金属图和碎片化小字。

字体使用 PingFang SC / Microsoft YaHei 与系统无衬线。字号按职责统一：正文和操作 16px，导航 15px，辅助说明 14px，最小元信息 13px；栏目标题 32px，内页标题 40px；首屏 AI+X 80px、中文赛事名 52px，手机分别 56px、36px。大字号只用于赛事名，正文在手机不缩小。

黑色 #0b0d0d，白色 #f1f3ed，说明色 #abb2ac；强调色 #d6fa78 仅用于当前状态与主要操作。平直分隔、明确边距，少量 4px 控件圆角。完整内容先于装饰。

## 结构

固定四栏目：介绍、赛题、图片视频、成果。右上角报名和历届切换保持可达。介绍首屏后紧接动态赛程，再是两条赛道和两场论坛。内页使用同一标题、正文和操作尺度；赛题阶段突出选中和当前状态。空内容如实显示，不虚构嘉宾、照片或奖项。
